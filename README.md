# Портфолио Абу-Бакира Кучкарова — рабочая копия

Это исходники опубликованной версии 4 персонального портфолио (состояние на 3 ноября 2026 года), подготовленные для локальной доработки в Claude Code на Windows.

## Где находится сайт

- `dist/index.html` — структура, стили, тексты и интерактивность сайта.
- `dist/locale-uz.js` — узбекская локализация.
- `dist/assets/` — фотографии, SVG-логотип и локальные библиотеки GSAP и Three.js.
- `dist/assets/covers/` — оптимизированные обложки проектов (уменьшенные копии оригинальных фото).
- `dist/assets/three.min.js` — Three.js r170 (MIT), обёрнутый в обычный скрипт `window.THREE`, чтобы 3D-сцена работала и при открытии файла напрямую, и на статическом хостинге.
- `backup-v4/` — версии `index.html`, `locale-uz.js` и `ak-mark.svg` до переработки v5.
- `CLAUDE.md` — постоянные инструкции для Claude Code.
- `ЗАДАНИЕ-ДЛЯ-CLAUDE.md` — готовый запрос, который можно вставить в Claude.

## Как работать в Windows

1. Распакуйте ZIP в удобное место, например `Документы`.
2. Установите приложение Claude для Windows: https://claude.com/download.
3. Откройте в нём вкладку **Code**, выберите **Local → Open folder** и укажите распакованную папку `abu-bakir-portfolio-claude`.
4. Откройте `ЗАДАНИЕ-ДЛЯ-CLAUDE.md` и скопируйте его содержимое в Claude. Попросите выполнить работу с файлами в этой папке.
5. Проверяйте результат в предпросмотре Claude либо открывайте `dist/index.html` в браузере. Для точной проверки локальных ресурсов и поведения лучше запускать локальный сервер.

Исходная опубликованная версия сайта не изменяется от работы над этой локальной копией. Для публикации новой версии потребуется отдельный шаг.
